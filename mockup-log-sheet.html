Badge states — A value row shows one badge per active state. Multiple badges can coexist (e.g. Positive + Challenged simultaneously, as in the rules). "Unused" collapses to a single grey pill. Clicking a badge removes that state; the + button adds one. The ★ star marks the log's primary value (used for chain-indent logic).
Context banner — Only shown when a callback link exists. Clicking it opens the source log. The arc pill on the right only appears when arcInfo.isArc === true.
Log options button — Moves the rarely-changed fields (trauma flag, show-milestone-arc toggle) out of a cryptically-named "Edit Log Data" collapsible into a small popover, reducing visual noise on the main sheet.
